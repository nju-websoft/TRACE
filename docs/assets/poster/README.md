# Poster artwork

These images are extracted from the supplied TRACE research poster
(`docs/files/trace-poster.pdf`), including its embedded transparency masks.
The whole-image VLM illustration uses an inline SVG to place the original
input flowchart, left-pointing pink beam, and thinking bubble at their exact
relative coordinates and scales from the poster. The website mirrors
the guide rabbit using CSS so it points left toward the title.
They are used to keep the project website visually consistent with the poster.

Institutional logos and illustrations retain their respective owners' rights;
the repository's Apache-2.0 code license does not grant rights to those marks
or third-party artwork. No new affiliation or endorsement is implied.

The QR code is the original poster QR and points to
https://github.com/nju-websoft/TRACE.
